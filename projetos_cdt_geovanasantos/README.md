# Resolucionador de Problemas

O sistema automatiza a busca por profissionais.

### Funcionamento

1. O usuário descreve o problema.
2. O sistema identifica o serviço.
3. Encontra profissionais automaticamente.
4. O usuário conversa com o profissional.
5. Pode negociar o preço.
6. O agendamento é confirmado.
7. Um comprovante é salvo em JSON.

### Bibliotecas

- Python
- Tkinter
- SQLite
- JSON
- Faker

### Executar

```bash
pip install Faker
python resolucionador.py
